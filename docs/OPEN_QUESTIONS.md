## Segment 1: Calendar

*Mostly answered 2026-10-07 (D37 through D49).*

1. When does an assignment count as **missed** and join the stack: when its planned start time passes and I haven't marked it done, or only when the deadline passes?
2. What should the default reminders for an assignment be (before I customize)? How far ahead of a deadline should the first warning come?
3. What categories do I want to start with (school, gym, BJJ, work, personal…)?
4. Since my school has no .ics, how is my schedule shown to me now (a web page, a PDF, an app)? Would taking a **screenshot** of it and having the app read it be useful? (iPhone can read text from images on-device, offline.)
5. How do I want to enter a class by hand: one screen with name, days, times, location and end date all at once, or something else?

## Segment 2: Inbox and tasks

1. When I tap the middle button, what's the very first thing I want to see?
2. What kinds of things do I throw in the inbox: tasks, reminders, ideas, notes?
3. How does an inbox item become "real"? Do I schedule it, give it a due date, or something else?
4. What's the difference between a to-do and a reminder for me, if any?
5. What should a reminder notification let me do right from the lock screen?

## Segment 3: Planning loop

1. What time at night should the "plan tomorrow" nudge come? Same every day, or different on weekends?
2. What counts as "I planned tomorrow"? Opening the app? Adding N items? Pressing a "done planning" button? Something else?
3. What time should the morning follow-up come if I didn't plan?
4. Should the follow-up be gentle, blunt, funny? Escalate if I ignore it?
5. Should missed planning count as a tracked streak too?

## Segment 4: Trackers

1. Full list of what I want to track right now (gym, BJJ, protein shake, Bible reading, anything else?)
2. For each: is it a streak, a days-since, a weekly count, or more than one?
3. Weekly targets for each (e.g. gym 4×/week)?
4. When does my week start?
5. Should completing a calendar block (e.g. "BJJ") check off the tracker automatically?
6. Do rest days break a streak?
7. How do I want to see progress: numbers, grids, rings, charts?
